## 1. Non-Negotiable Data Logging Rules
1. **Automated Recording from Day 1:** Every test run, whether on benchtop dyno, fan rig, or outdoor pad, must be automatically logged via hardware microcontroller at $\ge 1\text{ Hz}$. Manual pen-and-paper or smartphone screen photos are strictly invalid as primary engineering evidence.
2. **Synchronous Electrical Power Measurement:** Voltage ($V$) and Current ($I$) must be sampled simultaneously under defined electrical load:
   $$P_{\text{elec}} = V_{\text{load}} \times I_{\text{load}} \quad [\text{Watts}]$$
   *Open-circuit voltage ($V_{\text{oc}}$) multiplied by short-circuit current ($I_{\text{sc}}$) is strictly forbidden as a power metric.*
3. **True Energy Calculation:** Energy is calculated strictly as time-integrated power:
   $$E = \int P(t) \, dt \approx \sum P_i \cdot \Delta t \quad [\text{Watt-hours / kWh}]$$
4. **Calculated System Power Coefficient ($C_p$):** For every logged datapoint, calculate:
   $$C_p = \frac{P_{\text{elec}}}{\frac{1}{2} \cdot \rho \cdot A \cdot v^3}$$
   *Rule:* Use the exact measured rotor swept area $A$, NOT an assumed $1.0\text{ m}^2$. Air density $\rho$ defaults to $1.225\text{ kg/m}^3$ unless local ambient temperature and barometric pressure are logged.
5. **No Blind Curve Extrapolation:** Power curves must display raw scatter points, bin-averaged means (per IEC 61400-12 binning method, $0.5\text{ m/s}$ bins), sample count $N$, and standard deviation error bars. Never draw a smooth continuous curve through a few isolated points without labeling it as a mathematical fit.

## 2. Telemetry Hardware & Sensor Pinout

| Sensor Parameter | Sensor Model | Interface | Measurement Range | Accuracy / Uncertainty |
| :--- | :--- | :--- | :--- | :--- |
| **Wind Speed ($v$)** | Calibrated 3-Cup Optical Anemometer | Pulse Interrupt (ESP32 GPIO 14) | $0.4 - 30.0\text{ m/s}$ | $\pm 0.2\text{ m/s}$ |
| **Rotor Speed ($\text{RPM}_{\text{rotor}}$)** | Non-contact Hall-effect sensor + magnet on low-speed hub | Hardware Timer Interrupt (GPIO 27) | $10 - 1500\text{ RPM}$ | $\pm 1\text{ RPM}$ |
| **Generator Speed ($\text{RPM}_{\text{gen}}$)** | Optical reflective sensor on generator coupling | Hardware Timer Interrupt (GPIO 26) | $50 - 5000\text{ RPM}$ | $\pm 2\text{ RPM}$ |
| **DC Voltage & Current** | INA226 (16-bit ADC, $0.002\ \Omega$ high-precision shunt) | $I^2C$ Bus (Address 0x40, GPIO 21/22) | $0 - 36\text{V}$, $0 - 30\text{A}$ | $\pm 0.1\%$ |
| **Battery Bus V & I** | Secondary INA226 ($0.002\ \Omega$ shunt) | $I^2C$ Bus (Address 0x41) | $0 - 36\text{V}$, $0 - 30\text{A}$ | $\pm 0.1\%$ |
| **Temperatures** | DS18B20 1-Wire Digital Probes (Stator, Resistors, Ambient) | 1-Wire Bus (GPIO 4) | $-55^\circ\text{C} \text{ to } +125^\circ\text{C}$ | $\pm 0.5^\circ\text{C}$ |
| **Brake / Dump State** | Digital status pins on SSR / E-stop relay | GPIO Inputs (GPIO 32, 33) | 0 (Off) / 1 (Active) | Digital Boolean |
| **Local Storage** | Micro-SD Card Module (SPI interface) | SPI (MOSI 23, MISO 19, SCK 18, CS 5) | Up to 32 GB FAT32 | 100% Offline Resilience |
| **Cloud Uplink** | ESP32 Wi-Fi / MQTT client | Wi-Fi 802.11 b/g/n | HTTP/MQTT JSON Post | Auto-retry with local cache |

## 3. CSV File Format Schema & Header Specification
Every CSV log generated by the logger or imported into Yashwanth Hub must adhere to this exact column structure:

```csv
test_id,timestamp_utc,operator,prototype_id,rotor_config,gear_config,generator_id,load_type,load_resistance_ohm,wind_speed_mps,rotor_rpm,generator_rpm,drivetrain_ratio_actual,dc_voltage_v,dc_current_a,electrical_power_w,power_coefficient_cp,battery_voltage_v,battery_current_a,stator_temp_c,resistor_temp_c,dump_load_active,estop_active,observations
```

### Metadata Row Definitions:
- `test_id`: Unique string formatted as `PS-Txxxx` (e.g., `PS-T001`).
- `timestamp_utc`: ISO 8601 string (`YYYY-MM-DDTHH:MM:SS.sssZ`).
- `prototype_id`: e.g., `RIG-01-WOOD-PLANETARY` or `RIG-02-ALUM-POD-A`.
- `rotor_config`: `HAWT-SG6043` or `ARCHIMEDES-SPIRAL-V1`.
- `gear_config`: `MAG-GEAR-1TO10` or `PLANETARY-4STAGE`.
- `generator_id`: Exact generator model string.
- `load_type`: `RESISTIVE`, `ELECTRONIC_LOAD`, or `LIFEPO4_BATTERY`.

## 4. Automated Daily Analytics & Visualization Pipeline
Every evening by 8:00 PM, the telemetry pipeline executes an automated script processing the day's CSV logs:
1. **Wind Speed vs. Electrical Power ($P\text{-}v$ Scatter Plot):**
   - Plots raw 1 Hz scatter points.
   - Computes $0.5\text{ m/s}$ bin-averaged means with $\pm 1\sigma$ standard deviation bars.
   - Overlays theoretical available wind power ($P_{\text{wind}}$) and the Betz limit ($C_p = 0.593$).
2. **Tip Speed Ratio vs. Power Coefficient ($C_p\text{-}\lambda$ Curve):**
   - Plots calculated $C_p$ across the range of operating $\lambda$ to identify peak aerodynamic efficiency point.
3. **Generator RPM vs. Rotor RPM:**
   - Evaluates drivetrain speed ratio and flags any magnetic pole slip (Pod A) or mechanical clutch slip.
4. **Thermal & Safety Check:**
   - Verifies stator coil temperature and dump load resistor temperature remained within safe thresholds ($<85^\circ\text{C}$).
