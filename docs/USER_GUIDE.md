## 2. Universal Quick-Action Bar
Located directly on your **Home Dashboard**, the Universal Quick-Action Bar provides 1-click execution across 8 core workflows:

1. **Ask AI**: Launches Jarvis AI Assistant in your active workspace context.
2. **Create Task**: Focuses the quick-add task field with priority and due date controls.
3. **Schedule Event**: Opens the Calendar to schedule a lab review, customer meeting, or deep work session.
4. **Automation**: Opens the Automations Engine to review active triggers or run manual dispatches.
5. **Add Update**: Opens Projects to log a new prototype milestone or test run.
6. **Record Expense**: Opens the Finance modal to log components, travel, or machining costs.
7. **Capture Note**: Opens the Knowledge & Memory Vault to draft a technical memo or formula.
8. **Work Session**: Triggers the collaborative AI agent cursor tour for guided focus.
